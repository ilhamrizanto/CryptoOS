# Code Explainer Workflow

Ketika pengguna meminta penjelasan kode atau arsitektur menggunakan skill ini, ikuti langkah terstruktur berikut:

## 1. High-Level Summary (Gambaran Besar)
- Jelaskan tujuan utama kode/arsitektur dalam 1-2 kalimat.
- Berikan analogi dunia nyata yang relevan jika konsepnya abstrak.

## 2. Component & Flow Breakdown
- Pecah komponen utama menjadi poin-poin terstruktur.
- Gunakan diagram Mermaid (jika relevan) untuk memvisualisasikan alur data/eksekusi:
  - Input $\to$ Proses $\to$ Output.

## 3. Key Concepts & Best Practices Highlight
- Jelaskan pola desain (Design Pattern) yang diterapkan (misal: Factory, Singleton, Observer, dll).
- Sorot bagian kode yang krusial atau teknik optimasi yang digunakan.

## 4. Potential Edge Cases & Improvements
- Tunjukkan kemungkinan celah/bug atau area yang bisa ditingkatkan performanya.
- Berikan contoh perbaikan kode konkret jika ada.
